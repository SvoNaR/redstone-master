# Redstone Master

Клиентский Fabric-мод для Minecraft **1.21.11** с обучающими материалами по редстоун-механикам и связью с веб-приложением.

Автор: **Смирнов Григорий Витальевич**.

## О проекте

Redstone Master — окно поверх игры (без серверной части, `environment: client`). В моде доступны каталог уроков, настройки интерфейса, вход через сайт, синхронизация прогресса и комментарии к урокам.

Дополнительное веб-приложение находится в [`other_projects/redstone-master-web/`](other_projects/redstone-master-web/).

## Возможности

### Интерфейс

- Открытие по клавише **]**; закрытие — **X**, **Esc** или повторное **]** (настраивается)
- Центральная панель **60–100%** экрана (по умолчанию **80%**); по краям виден мир или фон меню
- **Прозрачность фона** — ползунок **0–100%** (стандарт **75%**): от полностью прозрачной панели до чёрного непрозрачного фона
- Высокий контраст рамок, локализация **ru / en**
- История навигации: **кнопка мыши 4** (назад), **кнопка мыши 5** (вперёд)

### Вкладки

| Вкладка | Описание |
|---------|----------|
| **Главное меню** | Описание проекта, благодарности, ссылки |
| **Обучение** | Каталог разделов и уроков, поиск, псевдо-видео, комментарии |
| **Настройки** | Параметры мода, поиск по настройкам, сброс |
| **Профиль** | Вход через браузер, синхронизация с сайтом, прогресс уроков |

### Обучение

- Разделы с раскрытием **◀ / ▼**, кнопка **«Изучить»** у каждого урока
- Поиск по разделам и урокам
- Текст, иллюстрации, **псевдо-видео** (последовательность PNG-кадров)
- Комментарии к урокам (требуется вход)
- Синхронизация пройденных уроков с веб-профилем

### Профиль и сайт

- Вход / регистрация открывает браузер на веб-сайте
- После входа в моде отображаются почта, роль, дата регистрации, прогресс
- Адрес сайта: `webBaseUrl` в `config/redstone-master.json` (по умолчанию `http://localhost:8080`)

### Поведение клавиши открытия

Окно **не открывается** по **]**, пока активен ввод текста:

- чат, таблички, книги;
- поиск во вкладке **Креатив**;
- поиск в **книге рецептов** (инвентарь, верстак);
- поля **Поиск** на вкладках **Обучение** и **Настройки** мода.

## Требования

| Компонент | Версия |
|-----------|--------|
| Minecraft | 1.21.11 |
| Fabric Loader | ≥ 0.19.2 |
| Fabric API | 0.141.4+1.21.11 |
| JDK (сборка) | 21 |

Для входа в профиль и комментариев нужен запущенный [веб-сайт](other_projects/redstone-master-web/README.md).

## Сборка

```bash
./gradlew build
```

Готовый JAR: `build/libs/redstone-master-1.0.0.jar`

Windows:

```bat
gradlew.bat build
```

## Запуск в среде разработки

```bash
./gradlew runClient
```

или `gradlew.bat runClient` / `run.bat`.

## Управление

| Действие | Клавиша / элемент |
|----------|-------------------|
| Открыть окно мода | `]` |
| Закрыть окно | **X**, `Esc` |
| Закрыть повторным `]` | Настройка «Закрывать мод по повторному нажатию» |
| Назад / вперёд по истории | Кнопки мыши **4** / **5** |
| Переназначение | Настройки Minecraft → Управление → **Redstone Master** |

## Настройки мода

Вкладка **Настройки** в окне мода:

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| Размер окна мода | 80% | Шаги 60–100% |
| Прозрачность фона | 75% | Ползунок 100% (прозрачно) → 0% (чёрный фон) |
| Пауза при открытии | Вкл | Пауза в одиночной игре |
| Высокий контраст рамок | Выкл | Белые рамки вместо чёрных |
| Автоподбор языка | Вкл | Язык Minecraft |
| Выбор языка | ru / en | При выключенном автоподборе |
| Сохранять вкладку и позицию | Вкл | Вкладка и прокрутка при повторном открытии |
| Закрывать мод по повторному нажатию | Вкл | `]` закрывает окно |
| Сворачивать другие разделы | Выкл | В обучении — один открытый раздел |

Также: **поиск** по настройкам, **сброс** одной настройки или всех сразу.

## Конфигурация

Файл: `config/redstone-master.json`

Основные поля:

- `panelScale`, `panelBackgroundTransparency` — размер и прозрачность окна
- `webBaseUrl` — URL веб-приложения для входа и API
- `profileLoggedIn`, `profileSyncToken`, … — данные сессии профиля
- `completedTutorialLessons` — локальный прогресс уроков

## Структура репозитория

```
src/client/java/ru/redstonemaster/
  RedstoneMasterClient.java       — точка входа, клавиши

    comments/                     — комментарии к урокам
    sync/                         — синхронизация прогресса
    video/                        — псевдо-видео
    ModOpenKeyGuard.java          — блокировка ] при вводе текста
  config/                         — ModConfig, языки, сессия

src/main/resources/
  assets/redstone-master/
    lang/                         — ru_ru.json, en_us.json
    tutorial/                     — каталог уроков (JSON)
    textures/                     — GUI, уроки, псевдо-видео

other_projects/redstone-master-web/  — веб-приложение (Spring Boot)
docs/TUTORIAL_SOURCES.md           — источники для уроков
```
